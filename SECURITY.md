# 🔐 Security Policy

## 📅 Supported Versions

We currently support only the latest version of `braisgf.dev`.

| Version | Supported         |
| ------- | ----------------- |
| Latest  | ✅ Yes            |
| Older   | ❌ Not maintained |

## 🐞 Reporting Vulnerabilities

If you discover a vulnerability in this project, please:

1. **Do not open a public issue.**
2. Send a detailed email to: **braisgf@gmail.com**
3. Include:
   - Steps to reproduce the issue
   - Expected vs actual behavior
   - Screenshots or code snippets (if possible)

We take security seriously and will respond ASAP.

Thank you for helping keep `braisgf.dev` safe and open 💙
