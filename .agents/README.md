# Arnes de agentes

`../AGENTS.md` contiene las reglas de desarrollo que deben aplicarse a todo el repositorio. `PERSONALIZATION.md` define el estilo de colaboración y el hábito de revisar el arnés. `SOURCE_OF_TRUTH.md` es el índice para cargar solo la guía pertinente a cada tarea.

Mantén esta carpeta para reglas concretas, decisiones verificadas y flujos de trabajo reutilizables. Evita copiar la misma instrucción entre archivos. Añade archivos `AGENTS.md` más específicos solo cuando haya una excepción o un flujo propio de esa carpeta.
